Historical student reports (2021)

This folder preserves eight reports from the two anonymous submission sources
already selected for the course repository. The PDFs retain their original
explanations, code screenshots, example parameters, and visible learning notes.
They are archival submissions, not corrected reports or evidence of correctness.

Student names, student numbers, personal executable paths, and document author
metadata were removed. The existing random aliases identify the published files.
PDF text redactions and screenshot pixel redactions were applied to the actual
content, followed by a full rewrite that removes unreferenced original objects.
Identity-bearing tagged /ActualText fields were also removed. The private source
filename-to-alias mapping is not part of this repository.

manifest.json records original and published SHA-256 hashes, page counts, and
each page's privacy edits. All 53 source and published pages were rendered and
reviewed. All 66 original embedded images were inspected in full, including
pixels outside the visible page crop. The nine affected embedded screenshots
were extracted again from the published PDFs and visually checked. Page text
and page renders were verified unchanged outside the identity substitutions.

A report's anonymous source does not establish authorship of a program found
beside it. Some historical folder and code attributions differ, so the archive
does not infer code authorship from report filenames or surrounding folders.
