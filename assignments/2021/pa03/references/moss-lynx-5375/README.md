# moss-lynx-5375：PA3 原稿與修正版

依 [2021-11-23 最新版作業說明](../../originals/PA3_20211123_2330_Andy.pdf) 修正。`original/` 是已知有錯的歷史原稿，供比較與重現問題；請使用 `fixed/` 的修正版。

| 版本 | 原稿 | 修正版 | 修正版執行檢查 |
|---|---|---|---|
| 一般版 | [original/basic.cpp](original/basic.cpp) | [fixed/basic.cpp](fixed/basic.cpp) | C++11、`-O0` 與 `-O2` 各 712/712 通過 |
| 除法加分版 | [original/division.cpp](original/division.cpp) | [fixed/division.cpp](fixed/division.cpp) | C++11、`-O0` 與 `-O2` 各 1029/1029 通過 |

原稿的減法直接對較小的數借位，未處理負號：`1 - 2` 印成 `99`，較大的負差值甚至會讀寫 vector 邊界之外。加分版的 `123 - 123` 沒有印出結果；除法使用 `s1[-1]`、`s2[-1]`，並把高位數轉成 `long long` 的冪與計數器，因此 `1 / 2`、`7 / 7` 及 100 位數除以 1 會失敗或逾時。選單輸入 `abc` 也會讓輸入串流一直停在失敗狀態。

修正版保留原本逐位 vector 加法、減法、乘法及平均數的結構。減法先比較正規化後的大小，較小被減數時交換運算元並印負號，相等結果固定印 `0`。乘法的進位迴圈明確限制於有下一位的位置。加分除法的機器整數冪／整體反覆相減演算法無法滿足 100 位數要求，因此改為十進位長除法：每次帶下一位、比較及逐位借位相減，每個商的位數最多減九次；商與餘數仍儲存在字串。這是對原稿的局部修復與除法替換，未取用本儲存庫的主解答實作。

輸入先檢查正整數、最多 100 個數字字元，再移除前導零；非數字、負數、零、過長數列均印一次錯誤並返回選單。選單使用有界的字串整數解析，保留原稿接受 `+1`、`01`、`-0` 等整數拼法的行為，也避免機器整數溢位與輸入串流卡住。平均數仍是 `(a+b)/2` 捨去小數，除法同時印商、餘數與平均數。

一般版的 712 項包括先前 60 項審查中的全部 57 個運算案例及 3 個選單案例、最新版題面範例、101 位加法進位、200 位乘積、相等／負差值、前導零、600 個固定種子的隨機有效運算，以及補充防呆、合法整數選單拼法與 EOF 檢查。加分版另含原本六個除法案例、其他邊界、前導零與 300 個獨立隨機除法。每項直接對照 Python 大整數的結果、整數平均數及 `divmod`；輸出須是完整且無多餘前導零的十進位字串。兩種最佳化設定均開啟標準庫邊界斷言。來源、修正版雜湊與已重現的原稿反例見 [validation.json](validation.json)。

原稿內容沒有姓名、學號或本機路徑，因此只用隨機目錄代稱及一般檔名匿名，原始位元組完整保留。SHA-256：

- 原稿除法版：`7ac67930e7ab6448b59cf5eaded9ec06c8f7f5f7bea10364399d2f6a270de1ca`

```sh
python tests/test_repaired_pa3.py --cxx g++ --with-originals
```

`--with-originals` 會重現原稿的已知失敗，並確認原稿確實不能當作已通過的解答。只編譯來源檔，不執行下載附帶的 EXE；每個新編譯程式在隔離目錄執行，限制時間與輸出大小。Windows 編譯採靜態 GNU 執行階段與不插入 PE 時戳的可重現連結設定；若需分開編譯與啟動，可先加 `--compile-only --work-dir <工作目錄>`，下一次改用 `--reuse-build --work-dir <相同工作目錄>`；重用前會核對來源、執行檔 SHA-256 與編譯參數。
