# cobalt-heron-2230：PA3 原稿與修正版

依 [2021-11-23 最新版作業說明](../../originals/PA3_20211123_2330_Andy.pdf) 修正。本候選的確切作者無法確認，因此使用獨立的隨機代稱，不推定與其他來源為同一作者。

- [original/basic.cpp](original/basic.cpp)：已知有錯的歷史原稿，供比較與重現問題。
- [fixed/basic.cpp](fixed/basic.cpp)：已修正的逐位陣列實作；C++11 `-O0` 與 `-O2` 各執行 712/712 項檢查通過。

原稿將較大數放在被減數陣列，但沒有輸出負號，`1 - 2` 因而得到 `1`。加法與平均數只留 100 位，100 個 `9` 加 `1` 會印 `0`，平均數也錯；100 個 `9` 加本身也遺失最高位進位。乘法雖配置 200 位陣列，卻只對低 100 位進位並列印，因此 200 位乘積被截斷。選單遇到 `abc` 無法恢復輸入串流；平均數的起始列印索引在全零的截斷結果下也可能未初始化。

修正版保留原有 `show_add`／`show_sub`／`show_mul`、固定陣列、逐位進位與借位的架構：加法與平均數擴至 101 位；乘積完整進位及列印 200 位；減法在交換運算元前記住比較結果並輸出負號；平均數索引明確初始化。讀入時先檢查正整數、最多 100 個數字字元，再正規化前導零。選單用不會溢位的有界字串整數解析，保留 `+1`、`01`、`-0` 等原本合法的整數拼法；錯誤輸入可回到選單，EOF 可正常結束。修正版的舊註解轉為 UTF-8，未取用本儲存庫主解答的演算法。

712 項包括先前全部 57 個有效運算案例、3 個選單案例，最新版題面範例、100 位數加法的第 101 位進位、200 位乘積、負差值／相等、前導零、600 個固定種子的獨立隨機運算，以及補充輸入防呆、合法整數選單拼法與 EOF。驗證直接對照 Python 大整數的結果與 `(a+b)//2`，並要求完整、正規化的十進位輸出；標準庫邊界斷言開啟。來源、修正版雜湊及四項已重現的原稿反例見 [validation.json](validation.json)。

原稿未內嵌姓名、學號或本機路徑，只更換目錄代稱與一般檔名，保留原始位元組及原來註解的編碼。原稿 SHA-256：`6e6f0c3e594ceb3ea3c0dd00e904f423014c024f1cac052792ebe680201cb0a3`。

從儲存庫根目錄重跑 [驗證程式](../../../../../tests/test_repaired_pa3.py)：

```sh
python tests/test_repaired_pa3.py --cxx g++ --only cobalt-heron-2230/basic.cpp --with-originals
```

`--with-originals` 會重現原稿的已知失敗；原稿不是已通過的解答。只執行由來源重新編譯的程式，每個程式限制時間與輸出大小。Windows 採靜態 GNU 執行階段、不插入 PE 時戳的可重現連結設定，也可分兩次呼叫：先加 `--compile-only --work-dir <工作目錄>`，再以 `--reuse-build --work-dir <相同工作目錄>` 執行；啟動前會核對來源、執行檔 SHA-256 與編譯參數。
