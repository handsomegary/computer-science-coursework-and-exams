# 匿名參考程式初次驗證紀錄（修復前）

這份紀錄保存修復前的篩選結果；下表「未收錄」是初次判定。後續已按最新版修復 13 份並同時匿名保存有誤原版，現況與測試證據見[修復與重新驗證](reference-repairs.md)。

核對 15 個候選來源：14 個有執行驗證，另有一份 PA1 早期稿僅編譯與靜態檢查。來源以隨機代稱呈現，沒有公開姓名、學號、原始個人檔名或本機路徑。一份 PA3 的資料夾與檔名標示不一致，作者無法確認，因此使用第三個獨立代稱。

初次審查保存 606 筆有界執行檢查紀錄（包含探索性的介面比對）。判定收錄時，以最新版明文規格、適用的公開案例與獨立有效輸入模型為依據；自訂 UI、空白差異或未規定的 EOF 行為不當作基本規格失敗。兩份收錄程式另外在匿名路徑重新編譯與重跑 99 組檢查，全部通過；最少損失版逐一核對 287 筆實際交易輸出，並檢查不得漏處理交易。

編譯器為 GCC 14.2.0、C++11，使用 `-Wall -Wextra -Wpedantic`；PA1／PA2 另用 `-Wconversion`。只執行重新編譯並檢閱過的程式，使用隔離工作目錄、逾時與輸出上限。數值測試使用 Python 整數／票券組合枚舉；PA4 使用獨立高精度 nodal 電路模型；Final 逐列模擬產生的 BENCH 電路。

各列通過率對應該版本的測試組，不代表課程成績，也不以相同測試數強行比較不同介面。PA1 找零擴充版採金額守恆檢查；最少損失版採最少支付金額的獨立枚舉模型，沒有強加未規定的平手付款規則。

PA3 三份來源均通過六個公開運算案例，PA4 三份均通過六個公開載入／操作案例及中段合併；上述拒絕原因仍有各自最新版合法輸入下的反例支持。Final 使用課程提供的 `kmap.cpp` 一起編譯，缺少同資料夾的相依檔案不是拒絕原因。

實際收錄的兩份程式與介面說明見 [moss-lynx-5375](../assignments/2021/pa01/references/moss-lynx-5375/README.md)。原碼沒有內嵌個人識別資料，因此只改代稱與檔名，未修改演算法；SHA256 可在該頁核對。

## 可重現的主要反例

- PA1：合法輸入 `0 p -1` 應完成零元交易後退出；有版本拒絕 0、接著卡在非法讀取。
- PA2：`8 -19 -11 0` 中第一個累加結果 −11 的最短二補數應為 `10101`；有版本印成 `1100101`。第 21 次一般版提示應為 `21st`。
- PA3：輸入兩個正數 1、2 選減法，結果必須為 −1；100 個 9 加 1 應得到 1 後接 100 個 0。
- PA4：最新版允許 15 個 stage，也允許無前綴電阻值；這些都是合法輸入，不是額外防呆要求。
- Final：二變數狀態表的 Gray-order 排列必須依 2×2 K-map 處理，不能沿用三／四變數的固定列交換。

## 課程支援程式

[原版 kmap.cpp](../assignments/2021/final/course_support/README.md)可確認為課程提供，無法確定教授本人撰寫。全部 65,808 個 2～4 變數函數的邏輯等價性通過；314 組精確最小性比對中有 54 組未達最少項數／literal，限制已列在來源頁。

```sh
python tests/test_reference_pa1.py
python tests/test_course_kmap.py
python tools/sync_solutions.py --check
```

可用 `--cxx` 指定編譯器。最新版題面與八份歷史版本的整理依據見 [版本核對紀錄](../assignments/version-notes.md)。
